# Tracking — External Sources *(bundled starter list)*

*A small Tier-0 starter so a fresh clone screens something recognisable before you
have supplied your own. **Used only when no real tracking file is present** — the
moment you add `universe.md` (or any other non-`.example` `*.md` here), this file
drops out entirely. Same rule as `input/sample.example.csv`.*

These are **not recommendations** — see [`DISCLAIMER.md`](../../DISCLAIMER.md).

## Why these nine, and why they are bunched

Tracking names are **radar-screened only**: they get flags, a 150-day line and a
sector-rotation vote, and **no gate card** in the daily evaluation. So the cost of a
tracking name is not the gate stack — it is two other things, and the second one is
easy to get backwards.

1. **A row in the radar report** the Trader reads every run.
2. **A sector in the rotation read.** The Analyst runs *one live web search per active
   theme* (`agents/analyst.md` §5), and the rotation read tags a sector on as little as
   one member — single-stock sectors get a 1-name floor. **So a list that spreads N
   names across N sectors buys N web searches**, every run, forever.

That second point is measured, not assumed. Against the bundled demo book:

| starter list | screened | tagged sectors → Analyst web searches |
|---|---|---|
| the old 40-name universe | 48 | 8 |
| 12 names, one per sector | 20 | **8** — no better, despite a third of the names |
| no tracking names at all | 8 | 4 |
| **these 9, in 3 sectors** | 17 | **4** — the floor, with the coverage kept |

So the nine below sit in **three sectors the demo book already holds** — Materials
(FCX), Defence (LMT) and Semis (NVDA). They add *depth* where there was one name,
clearing the 3-member floor a thin sector needs before its own cluster can carry a
read (`input/tracking/README.md`), and they add **no new sector** and therefore no new
theme search.

**Apply the same rule when you add your own.** Deepening a sector you already hold is
nearly free; opening a new one costs a web search on every future run.
